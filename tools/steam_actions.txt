# Steam Input actions: where each one is, its icon and its title in Steam's configurator.
# tools/steam_input.py reads this file and writes media/steam_input/ (manifest + layouts).
#
# Edit, then:
#   1. raise the second number of "revision" below (the first one only if an action id changed:
#      Steam then updates the players' layouts);
#   2. python3 tools/steam_input.py      (it checks this file against the mod's actions);
#   3. restart Steam: it caches the manifest until then;
#   4. in Steam pick the "Gamepad Tweaks" layout again and bind your buttons.
#
# Sections:
#   [set]                    always available: bind it in any layer, it works everywhere
#   [<layer>] EN | RU        declared in that layer: bindable and firing only while the layer is
#                            active; the rest of "EN | RU" is the layer's title in Steam.
#                            Layers stack bottom to top: onfoot or vehicle, then aiming, ui
#                            (any window focused), inventory or map on top of ui; menu alone.
#                            A binding in a lower layer still works while an upper one is active
#                            unless the upper one binds the same input.
#   Analog actions (aim, steer, move: for a gyro / trackpad / stick in Steam's "joystick" or
#   "mouse" picker) go in a section like buttons. steer and move take the place of the game's
#   stick (bind the stick to them, not to the xinput stick). Don't put a gyro on them: Steam
#   stops feeding a gyro into "joystick" output after a layer change until the game window
#   loses focus.
#
# Line: <action id>  <icon>  <English title> | <Russian title>
#   - the order of lines is the order in Steam's list (set first, then the active layer);
#   - icon: color emoji, several in a row are fine, no spaces; "-" for none. Text-style
#     symbols (⚙ ⏱ ↔) render small and monochrome unless followed by U+FE0F (as in ↔️);
#   - an action can be in one section only; moving it between sections is safe, renaming an id
#     is not (ids come from the Lua code).
# Every action of the mod must be listed; the script names missing and unknown ones.
