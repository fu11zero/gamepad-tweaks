# План: слои в ванильном редакторе геймпада

Запрос игрока: слои в «Настройки → Контроллер», как в Steam Input. Сверху — разнести действия по слоям,
а возможно, ещё и показать иконки. Это скорее наша недоделка. Изначально хотели, чтобы в игре
настраивались сила нажатия, долгое нажатие и двойной клик (старый план нигде не записан, восстановлен здесь).

## До реализации (на коммите fb87f08)

- Steam: 5 слоёв (`onfoot`/`vehicle`, `aiming`, `ui`, `inventory`), игрок сам решает, что в каком слое.
  Слои выбирает `Bindings.lua` каждый кадр (`GamepadTweaks_steamInputSetLayers`).
- Ванильный редактор (`ControllerEditor.lua`): на кнопку один список. Внутренние слои действий
  (`world`, `cruise`, `aiming`, `hold`, `uiHold`, `navigation`) зашиты в `layer = ...` каждого действия
  в `Bindings.lua`, игрок их не видит и не выбирает.
- Бинды мода: `preset.<имя>.bind.<действие>` в `GamepadTweaks.properties`.

## Шаги (каждый можно выпускать отдельно)

1. **Слои для действий мода — реализовано.** Вкладки «Общие», «Пешком», «Транспорт», «Прицел»,
   «Панели», «Инвентарь» и «Круиз». Хранение `preset.<имя>.<слой>.bind.<действие>` с миграцией
   старых строк. Назначение и срабатывание биндов проверены игроком в игре.
   Отдельная вкладка «Круиз» по итогам первой проверки выглядит избыточной.
2. **Иконки.** Если иконки Steam-действий есть в png, показывать их в строках редактора (`getTexture`). Дёшево.
3. **Модификаторы нажатия:** порог триггеров (ванильные `isRTPressed` > 0.7, Attack 0.93), долгое
   нажатие, двойной клик, аккорды. Для действий мода — на базе `ButtonLatch`, `PressActions`,
   `HeldActions`, это несложно. Для ванильных биндов нужен перехват `TimedInputHandler`
   (pressed/released/clicked за 400 мс): это рискованная часть.
4. **Ванильные бинды по слоям** (например, Crouch пешком и другое в машине). Их опрашивает Java через enum
   `CharacterJoypadButtonBinding`, нужен патч, который ищет кнопку бинда с учётом текущего слоя. Часть
   биндов живёт в Lua (`ISButtonPrompt`, `getBestButtonBindingAction`, см. AGENTS.md про затирание
   подсказок), их разбирать отдельно. Объём большой.
   На этом же шаге рассмотреть подслои в редакторе. Первый пример — «Круиз» внутри «Транспорта»,
   который активируется у водителя при удержании кнопки круиз-контроля.

Порядок: 1 → 2 → 3 (сначала для действий мода) → 4.
